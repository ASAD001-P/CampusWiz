# CampusWiz

CampusWiz is a RAG-powered AI chatbot that digitizes university notices and provides answers to student queries using a Mistral LLM and custom temporal logic.

## Features

* Retrieval-Augmented Generation (RAG)
* University notice processing
* Mistral LLM integration
* Time-sensitive query handling
* Custom temporal logic

## Technologies

* Python
* Mistral LLM
* Retrieval-Augmented Generation (RAG)

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ASAD001-P/CampusWiz.git
```

Install the required dependencies and follow the project instructions to run CampusWiz.

## Purpose

This project explores the use of RAG and temporal reasoning to make university notices easier to access and query.
